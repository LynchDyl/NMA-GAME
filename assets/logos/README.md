# Logos

The games show a small credit bar for the **National Marine Aquarium** and the
**Ocean Conservation Trust**. By default these appear as styled text wordmarks.

If you have the right to use the official logo artwork, drop the image files
in this folder and they will appear automatically next to the text:

- `nma.png` — National Marine Aquarium logo
- `oct.png` — Ocean Conservation Trust logo

Recommended: transparent-background PNG (or SVG renamed appropriately), roughly
60–120 px tall. If a file is missing, the game simply hides the image and keeps
the text wordmark, so nothing breaks.

> Note: the official NMA / OCT logos are trademarks of those organisations.
> They are intentionally **not** bundled in this repository — add your own
> licensed copies here only if you have permission to use them.
