# 🐢 Scrub Friday the Turtle!

A browser game inspired by **Friday the turtle** at the **National Marine
Aquarium in Plymouth**. Friday's shell keeps getting colonised by *Aptasia*
anemones — your job is to scrub them all off and keep him healthy!

## How to play

- Open `index.html` in any modern browser (or serve the folder over HTTP).
- Click / tap each pink **Aptasia** spot to scrub it off Friday's shell.
- Clear every spot to **level up** — more spots appear and the timer gets
  shorter each round.
- Rack up the highest score before time runs out!

## Files

| File | Purpose |
|------|---------|
| `index.html` | Markup, turtle SVG and overlay |
| `style.css`  | Styling, animations and layout |
| `game.js`    | Game logic: spawning, scoring, timer, levels |

No build step or dependencies — it's plain HTML/CSS/JS.
